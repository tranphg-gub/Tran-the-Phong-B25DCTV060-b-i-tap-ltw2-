# Bài 1 — Virtual Calculator

Ứng dụng máy tính React độc lập.

- `CalculatorDisplay` hiển thị biểu thức và kết quả.
- `CalculatorButton` nhận nhãn, kiểu và hành động qua props.
- State lưu số hiện tại, toán tử và kết quả trung gian.
- Hỗ trợ `+`, `−`, `×`, `÷`, `%`, đổi dấu, `DEL`, `C` và `=`.

## Chạy dự án

```bash
npm install
npm run dev
```
