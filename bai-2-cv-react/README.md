# Bài 2 — CV React

Trang CV React độc lập.

- Các component chính: `Hero`, `Section`, `SkillGrid`, `ProjectList`, `ContactForm`.
- Dữ liệu kỹ năng và dự án được đặt trong mảng rồi truyền qua props.
- `Section` nhận nội dung qua `children`.
- Có responsive, dark/light mode, tìm kiếm/lọc dự án và kiểm tra form.

## Chạy dự án

```bash
npm install
npm run dev
```
